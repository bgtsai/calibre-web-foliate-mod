# v1.79 規格：閱讀進度、預覽連結、跳轉紀錄保存、書籤、搜尋、匯出

狀態：第一版實作依據（2026-10-13 與使用者討論定案；未定細節由 Claude 先提方案，實際操作後再調）。

## 0. 名詞
- **閱讀進度**：讀到哪裡。沿用 Calibre-Web 原本的書籤欄位（`/ajax/bookmark/<id>/epub`，一本書一個 CFI）。
- **書籤**：使用者手動加的位置，一本書可以很多個。三種：**定位**（只有位置）、**摘錄**（有選取文字）、**備註**（有備註；可同時附摘錄）。
- **定位網址**：`<書本閱讀網址>#cfi=<encodeURIComponent(epubcfi(...))>`。
- 介面、提示、除錯紀錄中代指閱讀進度的「書籤」一律改成「閱讀進度」。

## 1. 閱讀進度
| 項目 | 規格 |
|---|---|
| 設定 | 「閱讀進度同步至雲端」（原「停留頁面自動加入書籤」）在上；「雲端紀錄優先」（取代「本機自動記憶」，預設開）在下，附說明：沒開同步時雲端只在手動更新，可能較舊。刪除「停留幾秒後加入書籤」。|
| 本機記錄 | 一律儲存（每次換位置）。預覽模式不寫。|
| 開書順序 | 定位網址 ＞（雲端紀錄優先 ? 雲端→本機 : 本機→雲端）＞ 從頭。|
| 同步時機 | 開啟同步時每次換位置立刻送；同時只送一個，送出中再變動只記最新，前一個完成再送。預覽模式不送。|
| 離開補送 | `pagehide`／`visibilitychange→hidden` 時，只有「還沒送出的變動」才用 `fetch keepalive` 補送（沒動過的分頁不寫，避免蓋掉其他分頁/裝置）。|
| CSRF | 回 400 時讀回應內容寫進錯誤紀錄；判定為 CSRF 失敗就重新取得頁面上的 token（GET 目前閱讀頁解析 `csrf_token`）再重送一次。|
| 精準對位 | 精準定位開啟時，開書用「還原來源的 CFI 起點字」當鎖定點並重新排版，讓那個字成為畫面第一個字。|
| 工具列書籤鈕 | 改成「加書籤」，固定空心，不再代表閱讀進度。|

## 2. 預覽模式（定位網址）
- 網址帶 `#cfi=` 開書 → 進入預覽：跳到該位置並精準對位。
- 預覽中：閱讀進度（本機、雲端）與跳轉紀錄都**不寫入**；跳轉紀錄照常運作（記憶體）；可加書籤。
- 工具列下方一行提示條：「預覽模式・閱讀進度不會儲存」＋〔正式閱讀〕。工具列自動隱藏時提示條貼到畫面頂端，不隱藏。
- 預覽中 `#cfi=` 隨目前位置更新（`history.replaceState`），重新整理仍是預覽、停在剛才的位置。
- 按〔正式閱讀〕：結束預覽、移除 `#cfi=`、立刻把目前位置寫入閱讀進度（本機＋雲端，依設定）。
- 登入（僅 Docker）：登入頁偵測 `#cfi=` 且 `next` 指向閱讀頁 → 存 sessionStorage（分頁內有效、無時效）；閱讀頁沒有 `#cfi=` 但暫存是同一本書 → 使用並刪除。Tampermonkey 版不做（登入後自己再開一次）。

## 3. 跳轉紀錄保存
- 四組：目錄、書內連結、進度條、**搜尋**（新）。
- 有變動才存（record/back/forward/clear），存檔前先把「目前這格」補成當下位置；預覽模式不存。
- 開書讀回；多分頁／多裝置以最後一次變動為準。
- 儲存：Tampermonkey＝GM（每本書一個 key `cwfm-bookdata-<id>`）；Docker＝伺服器 API。

## 4. 書籤
- **資料**：`{ id, cfi, excerpt?, note?, name?, chapter, fraction, created, modified }`。類型由內容推得：有 note＝備註；否則有 excerpt＝摘錄；否則＝定位。
- **位置**：一律跟著文字。定位＝建立當下畫面第一個字；摘錄＝選取範圍。
- **預設名稱**：備註前 20 字 ＞ 摘錄前 20 字 ＞ 建立時間 `YYYY-MM-DD HH:MM:SS`；使用者可改，清空則恢復預設。
- **加書籤**：工具列書籤鈕 → 視窗（摘錄預覽〔可移除〕、名稱、備註、取消／儲存）。選取文字在選取當下就記住（iOS 點工具列可能取消選取）；按鈕按下後 1 秒內的「選取被取消」不清除記錄。
- **跳轉**：定位＝該字成為畫面第一個字；摘錄＝跳到包含它的頁並標示。從目錄點書籤算正式閱讀，記入目錄跳轉紀錄。
- **內文標示**：有摘錄的書籤用淡底色標示（引擎註記圖層，不改內容），點標示打開目錄並展開該書籤。設定「顯示書籤標示」開關，預設開。
- **目錄混排**：插在所屬章節（同章節取第一個目錄項）底下；統一的「橫躺小書籤」造型（左側尖角旗頭），旗頭顏色＋圖示分類（定位灰／時鐘、摘錄琥珀／引號、備註青綠／鉛筆）。點本體＝跳轉；右側虛線隔開的 ▾＝原地展開（完整摘錄、備註、時間、〔編輯〕〔複製連結〕〔刪除〕）。
- **篩選**：目錄頂端〔章節〕〔定位〕〔摘錄〕〔備註〕多選切換，記住狀態。
- **刪除**：確認視窗。
- **儲存**：Tampermonkey＝GM；Docker＝伺服器（逐筆新增／修改／刪除，不整包覆蓋，避免多裝置互蓋）。

## 5. 面板位置
- 目錄、設定、搜尋面板改到工具列下方（top 48px），工具列在面板開啟時不自動隱藏；再按同一個按鈕可關閉面板。

## 6. 搜尋
- 工具列放大鏡 → 搜尋面板（同面板位置），面板頂端輸入框、↑↓、「第幾個／共幾個」。
- 範圍〔全部〕〔內文〕〔書籤〕附筆數；書籤搜尋名稱、摘錄、備註。
- 比對：不分大小寫、全形半形視為相同、**簡繁互通**（逐字繁→簡對照，資料來源 OpenCC TSCharacters＋TWVariantsRev，Apache-2.0；只做單字，不處理詞彙差異）。
- 結果：書籤在前；內文依章節分組、顯示前後文與全書百分比、關鍵字標亮；逐章陸續出現並顯示進度；內文同時用引擎標示所有命中。
- 點結果：記入「搜尋」跳轉紀錄後跳過去，結果列反白「目前位置」。關面板保留結果；清空輸入才清除。

## 7. 匯出
- 目錄面板標題列的匯出鈕 → 選格式：HTML（預設）、Markdown、CSV；範圍：目前這本書、套用目前篩選。
- HTML：頁首（書名、作者、匯出時間、各類數量）；依章節分組；每筆一張卡片，欄位一行（名稱／位置／摘錄／備註／時間／連結），右側小標記標類型與百分比；附定位網址（點了以預覽模式打開）。
- 下載用 Blob＋`a[download]`。

## 8. Docker 後端
- `cps/cwfm_api.py`（Flask blueprint，`user_login_required`，沿用 CSRF）；資料存 `/config/cwfm.db`（SQLite，不動 `app.db`）。
  - `GET  /cwfm/api/` → 健康檢查
  - `GET  /cwfm/api/book/<id>` → `{bookmarks:[...], navhist:{...}|null}`
  - `PUT  /cwfm/api/book/<id>/bookmark/<bmid>`、`DELETE` 同路徑
  - `PUT  /cwfm/api/book/<id>/navhist`
  - 單次請求上限 256KB；書籤 id 限 `[A-Za-z0-9_-]{1,40}`。
- 建置時把 blueprint 註冊插進 `cps/main.py`（`app.register_blueprint(editbook)` 後，必須剛好 1 處，否則建置失敗）。
- `read.html` 開機段落多給 `api` 網址與本機 `bookdata`；`login.html` 加暫存定位腳本。
- CLAUDE.md 加例外：後端 API 放 Docker repo，介面仍在 mod repo。

## 9. 自我檢查（風險與處理）
| 風險 | 程度 | 處理 |
|---|---|---|
| 即時同步請求量變多 | 低 | 一次一個、只送最新；書籤字串很小 |
| 沒動過的分頁離開時蓋掉新進度 | 中 | 只補送「未送出的變動」|
| 預覽模式誤寫進度 | 中 | 所有寫入點統一檢查 `cwfmPreview` |
| iOS 選取被工具列取消 | 中 | 選取當下就記住＋按下後 1 秒保護 |
| 書籤 CFI 在書檔替換後失效 | 低 | 跳轉失敗時提示，不刪資料 |
| 全書搜尋效能（大書）| 中 | 逐章非同步、可中途取消（重新搜尋即取消前一次）|
| 簡繁對照改變字串長度 | 低 | 只收單一 UTF-16 單位互換的字，位置不變 |
| 上游 Calibre-Web 改版讓 main.py／login.html 對不上 | 中 | 剛好 1 處檢查，失敗即建置失敗 |
| Docker API 不可用 | 低 | 讀取失敗退回本機（localStorage），並記錯誤 |
| 多裝置同時改跳轉紀錄 | 低 | 最後變動為準（已同意）|
| 舊設定 `localAutoRemember=false` 的人 | 低 | 本機記錄改為一律存，屬預期行為 |
| 檔案大小增加（對照表約 18KB＋新功能）| 低 | 可接受 |
| 與既有精準對位、跳轉紀錄互動 | 中 | 重用 `cwfmNavGoToPos` 同一套對位流程，跑完整回歸測試 |
